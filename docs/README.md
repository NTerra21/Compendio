# Fuentes originales (DOCX)

Esta carpeta guarda los **documentos Word originales** de los personajes.

- Son material historico / de referencia.
- La pagina web **NO** los lee para funcionar.
- La informacion que usa la app esta en `js/characters/*.js`.

## Cuando consultar estos archivos

- Recuperar informacion que no esta en el `.js`
- Verificar discrepancias
- Ampliar el trasfondo de un personaje

Para el mantenimiento diario del sitio, edita solo `js/characters/Nombre.js`.
